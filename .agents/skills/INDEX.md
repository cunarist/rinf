# Rinf Agent Skills Index

Use these focused skill notes for repeatable project workflows. Each file is self-contained and should be updated when a workflow gains a new gotcha.

## Skills

- [signal-types.md](signal-types.md) — add or modify signal DTOs, signal derives, serde attributes, and receiver/sender usage.
- [code-generation.md](code-generation.md) — run `rinf gen`, diagnose malformed output, and handle generator/tool version problems.
- [platform-builds.md](platform-builds.md) — troubleshoot Android, Apple, Linux, Windows, web/WASM, ohos, library loading, and lifecycle issues.
- [cargokit.md](cargokit.md) — update vendored Cargokit while preserving upstream context and platform coverage.
- [ci-cd.md](ci-cd.md) — triage CI failures, lint ordering, generated bindings, and Dependabot PRs.
- [versioning.md](versioning.md) — perform release version bumps without hidden local-patch mismatches.
