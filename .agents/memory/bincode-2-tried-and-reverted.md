Commit ae83b0b4 ("Use `bincode` 2.0", 2025-03-10) was reverted within the day (bbdb2db5). `rust_crate/Cargo.toml` still pins `bincode = "1.3.3"` and `lib.rs` re-exports `bincode::{deserialize, serialize}`. The commit messages give no reason, but the Dart side is generated by `serde-generate` with its bincode runtime, which defines the wire format, so a Rust-only bump risks desyncing the ends. Treat a bincode major bump as a cross-language wire change that needs the Dart generator verified. Dependabot is off for cargo anyway, see [[dependabot-limited-to-github-actions]].

Evidence: commits ae83b0b4, bbdb2db5; rust_crate/Cargo.toml
